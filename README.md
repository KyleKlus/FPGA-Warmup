# FPGA-Labor - Gruppe XX, Teilnehmer 1, Teilnehmer 2
Dieses Repository umfasst die Versuchsdateien,
welche für die Bearbeitung des Labor: FPGA-Entwurfstechnik benötigt werden.

## Versuche
- Versuch 1: Entwurfsablauf anhand eines 4-Bit-Zählers
- Versuch 2: Funktionale Beschreibung eines Synchron-Zählers
- Versuch 3: Synchron-/Asynchron-Addierer
- Versuch 4: Infrastruktur
- Versuch 5: S2P-Unit (Seriell-/Parallelwandlung)
- Versuch 6: Mixer-Unit
- Versuch 7: Gain-Control
- Versuch 8: Delay-Unit

## Ordnerstruktur
Für jeden Versuch gibt es einen Ordner mit folgenden Unterordnern:
- ```quartus/``` Quartus-Projektdateien für Emulation
- ```questasim/``` QuestaSim-Projektdateien für Simulation
- ```testbench/``` Testbench-Code für Simulation
- ```vhdl/``` Hardwarebeschreibung für Simulation, Synthese und Emulation
